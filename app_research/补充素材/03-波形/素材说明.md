# 433 载波与指令｜6 秒原理插镜

把 **433载波与指令.mp4** 放在口播“频率得对，门还得认得指令”这一句附近。第一行是连续载波；第二行是按示例位串 `10101` 对同一载波进行开关后的信号。两行共用时间轴，扫完后约有一秒停留。已留出底部字幕位置；另有静帧 **波形定格.png** 可直接放进剪映。

这是 **射频信号随时间变化的波形**，不是量子力学中的波函数。示例采用开关键控（OOK）：1 发射载波，0 停发。这不是手上遥控器的实测波形，不表示门用 `10101` 作为开门码，也不表示所有 433 MHz 遥控器都用 OOK。频率和位宽只作图解，转为人眼可辨的节奏，不能从画面读出实际码率。

公式：上行 `c(t) = A·sin(2πfc·t)`，下行 `s(t) = b(t)·c(t)`，其中 `b(t)` 取 0 或 1。图上每位画两个示意周期，未按真实时间尺度绘制。依据：[Microchip，ATA8510/15《Modulation Settings》→ RF Modulation](https://onlinedocs.microchip.com/oxy/GUID-74578654-4F5F-4B29-9F3C-6C3B1F1DF670-en-US-2/GUID-4C33B250-E14C-4F8E-8466-A2224E34486D.html)。该资料说明一种发射实现，不是对本地设备型号或编码方式的鉴定。

**433载波与指令.svg** 是可离线直接打开、6 秒循环的 SVG。要复用，修改 **波形模板.mjs** 顶部的 `bits`、配色或文字，在本目录运行：

    node 波形模板.mjs --export    # 更新 SVG、MP4
    node 波形模板.mjs --still     # 更新定格 PNG
    node 波形模板.mjs --verify    # 核对视频规格

重新渲染使用 Node、rsvg-convert、FFmpeg、ffprobe 和本机中文字体，不需要联网或打开浏览器。MP4 为 1080×1920、H.264、30 fps、180 帧、无音轨。
