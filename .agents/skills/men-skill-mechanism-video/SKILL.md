# 门体原理动画与剪映插镜

先在[作品索引](../../../content/INDEX.md)找选题和对应制作源，核对这段画面要配哪一句口播。收到实拍、型号资料或师傅对动作的更正时，以它们确定该镜头的视角、运动和可见零件。资料只覆盖外观时，把内部动作标作原理示意。

## 选择制作入口

- 修改“手机为什么不能直接开门”时，从[手机遥控插镜工程](../../../app_research/使用说明.md)开始。已有模板复用同一扇外卷门、控制器和初始状态。改文字和时序可复用门模型缓存，改外卷几何才需重新生成缓存。定版素材和剔除旧卷向的原因见[1.0 交付包](../../../resource_1.0/README.md)。
- 做新的卷绕演示时，从[通用卷绕模型与制作说明](../../../content/卷帘门卷绕动画version1/制作说明.md)借用运动模型。轴测几何、明暗和遮挡可复用通用 `anatomy`。完整重建通用模型时可用 `ANATOMY_DIR` 指向安装目录。[交付快照](../../../resource_1.0/05-可编辑工程/README.md)内带两个许可模块，只够复现该快照注明的步骤。

## 从原理到插镜

1. 写清机位在哪一侧、固定件是什么、哪个动作应当看得见。以外卷门为例，先给出闭合、上卷途中和打开的关键帧，核对卷轴在门帘哪一侧、帘片从哪里入卷。用局部剖视时标明省略的罩壳。实物的指示灯功能、接线或尺寸须有对应依据。
2. 沿用或新建该选题的可编辑工程。把时间、颜色和短标注放在可修改的配置中。卷绕画面复用固定轴和导轨、帘片连续、材料长度守恒等约束。信号或灯效示意按口播表达，声称实测的数据须有采集记录。
3. 按该工程说明构建并核对模型、遮挡和关键帧。下列命令可在主仓根验证两套现有卷绕模型。检查导出时沿用[浏览器规则](../../../docs/rules/playwright.md)，使用无窗口实例。

   ```bash
   node --test 'content/卷帘门卷绕动画version1/model.test.mjs' app_research/src/exterior.test.mjs
   ```

4. 按当期时长导出。剪映插镜默认 9:16、H.264、无音轨，底部预留正片字幕，文字量适合直接剪入。用 `ffprobe` 核对实际时长、画幅、帧率和音轨，看片确认动作方向及切点。交付 MP4、可编辑入口，按需附定格图。定版后在素材清单登记用途、来源、示意边界、校验值和恢复位置，更新作品索引中的制作或交付入口。修改旧版时在制作源或快照副本操作，保留已经交付的版本。
