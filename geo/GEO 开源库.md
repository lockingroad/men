## 第一梯队
### oneglanse

GEO 监控系统
https://github.com/aryamantodkar/oneglanse


**最值得学习：**

- 真实 UI 和 API 回答的区别；
- 登录态保存；
- Provider Adapter；
- 浏览器 Worker；
- Prompt 任务队列；
- 引用卡片提取；
- ClickHouse 时序统计；
- 品牌、竞品、来源三类实体分析。

**主要缺点：**

- 浏览器自动化非常脆弱；
- AI 网站改版后 Selector 会失效；
- 登录可能触发验证；
- VPS 可能需要住宅代理；
- 存在平台服务条款、频率限制和反自动化风险。


### ai-search-guru/getcito-worlds-first-open-source-aio-aeo-or-geo-tool

https://github.com/ai-search-guru/getcito-worlds-first-open-source-aio-aeo-or-geo-tool

- Prompt、Brand、Competitor、Run、Response 的数据库设计；
- 任务调度、重试和幂等性；
- Scraper Provider 与 LLM Provider 抽象；
- 原始快照和分析结果分开存储；
- API、Worker、Dashboard 分层；
- 自托管和多租户设计。

**主要缺点：**

真正抓取 ChatGPT、Google AI Mode 等产品时，往往仍然依赖 Bright Data、Oxylabs、DataForSEO 等商业数据服务，并不是完全零成本。\
