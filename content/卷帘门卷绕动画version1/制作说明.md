# 卷帘门怎样卷起来 · Anatomy 动画小样

## 制作目标

12 秒、1080 × 1920、30 fps，无配音的通用结构示意。只解释一个机制：相互连接的帘片沿固定导轨上升，在上方弯折并逐层卷到水平卷轴上，反转后沿原路放下。

采用 Anatomy 的 Figure（单机制）制作层级；使用官方轴测几何与明暗工具，不启用 WebGL 或测试阶段的交互 3D 引擎。竖屏的视频版式优先于默认网页卡片版式。

## 真实性边界

- 通用示意，不对应具体品牌或型号，不作为安装尺寸、受力计算或接线指导。
- 卷轴中心与导轨固定；门帘材料长度和片数守恒，卷入后卷径增加。
- 上端有初始卷绕与连接，底梁保持独立，不吞入卷层。
- 用等效层厚和简化帘片截面说明卷绕。省略真实钩口、端锁、电机内部、弹簧和限位电路。
- 上罩和局部遮挡件省略，便于看清卷绕；不代表实物应裸露运行。

## 零件计划（几何前确定）

- 基础：底座 1、支柱底板 2、安装螺栓 8。
- 支撑：立柱 2、后横梁 1、导轨连接座 6。
- 导向：左右导轨各 3 个槽壁，共 6。
- 卷轴：轴芯 1、两侧轴颈 2、轴承座 2、支承板 2。
- 主体：固定编号的连续帘片约 40 片、底梁 1、底部密封条 1。
- 细节：真实接合边、安装孔、轴端旋转标记；不添加无功能装饰零件。

## 画面与时间

0–1 秒闭合；1–6.5 秒卷起；6.5–8.5 秒保持；8.5–11.5 秒放下；11.5–12 秒闭合。

以第 29 片（程序编号 28）深色帘片作为追踪标记。白底、金属灰主体、清楚的边缘和侧面层次；标题、状态字幕位于机器之外，主要文字避开右侧按钮区，并为底部界面信息预留空间。实际抖音界面遮挡仍可能随版本和展开状态变化。

4.9–8.35 秒切换为同一模型的卷绕侧面放大，露出轴芯、简化连接片及卷层；明确标注“局部剖开示意”。主视图与侧视图共用材料长度、帘片编号和时间轴。

## 文件与复现

- `卷帘门怎样卷起来-v1.mp4`：12 秒、1080 × 1920、30 fps、H.264、无音轨。
- `preview.html`：可离线打开的交互预览，支持播放、暂停、重播及拖动进度。
- `preview-dark.html`：深色检查版，正式视频使用浅色版。
- `model.mjs` / `model.test.mjs`：纯运动模型及测试。
- `scene.mjs` / `closeup.mjs` / `order.mjs`：主视图、侧视图及实时遮挡排序。
- `build.mjs` / `live.js` / `style.css`：生成页面、时间控制和版式。
- `render.mjs`：独立 headless Chrome 逐帧截图，再编码为 MP4，不使用个人浏览器 profile、不连接外网。
- `qa/`：关键帧、近景、浏览器检查及几何审计记录。
- `LICENSE-Anatomy.txt`：内嵌 Anatomy 工具代码的 MIT 许可。

```sh
node --test 'content/卷帘门卷绕动画version1/model.test.mjs'
node 'content/卷帘门卷绕动画version1/build.mjs' --audit
node 'content/卷帘门卷绕动画version1/build.mjs' --dark
node 'content/卷帘门卷绕动画version1/render.mjs'
```

构建默认读取本机安装的 Anatomy，可用 `ANATOMY_DIR` 指定另一安装目录。最终 HTML 已内嵌运行代码，不需要该技能目录或服务器；重新构建需要。渲染脚本的 Playwright 路径对应本机 Codex 依赖包，移到别的电脑需按环境调整。
