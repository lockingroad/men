## 03｜查证：四篇完整官方文档

[打开官方整页目录](03-官方整页/整页目录.md)。每篇均保留 **可搜索的 MHTML + 原始整页 PNG + 首尾完整的滚动 MP4**，并附采集记录。网页用 Chrome / Edge 打开，长图和滚动视频可直接导入剪映。

| 编号 | 官方文档 | 核对内容 |
| --- | --- | --- |
| D01 | Android · ConsumerIrManager | 红外硬件检测与红外发射；搜索 `hasIrEmitter`、`transmit`。 |
| D02 | Android · BluetoothLeAdvertiser | 蓝牙广播；搜索 `startAdvertising`。 |
| D03 | iOS · Core Bluetooth | 蓝牙框架所支持的设备及通信范围；搜索 `Overview`。 |
| D04 | iOS · startAdvertising(_:) | 蓝牙广播方法的参数；搜索 `advertisementData`。 |

**取证边界：** 文档能说明这些接口发的是哪种信号，不能证明所有手机都没有 433 MHz 天线。433 MHz 是频率，不是统一的开门协议；手机经兼容控制器开门与手机直接发传统遥控信号也不是一件事。

## 从 Git 恢复本期素材

在包含 1.0 素材包的主仓版本中，清单 48 项里有 42 项可按相对路径直接检出，包含 4 张实拍参考照、整页 PNG 和 MHTML、编辑工程及许可证。另 6 项是本机导出的 MP4。清单的“恢复方式”列可筛选这两类。口播原片单独归档在 [appv1](../content/appv1/appv1.md)，该原片也可随主仓检出。

| 视频编号 | 本机原导出位置（相对主仓） | 仅持有 Git 副本时怎样取得画面 |
| --- | --- | --- |
| V01 | `app_research/遥控信号对比.mp4` | 复制 [05-可编辑工程](05-可编辑工程/README.md)，在副本根运行 `node app_research/src/export.mjs`。脚本从已保存的 SVG 导出同名视频。 |
| V02 | `app_research/补充素材/05-四种信号对照/四种信号对照.mp4` | 在上述工程副本根运行 `node app_research/补充素材/05-四种信号对照/对照模板.mjs --export`。MP4 生成在该模板旁。 |
| D01-V 至 D04-V | `app_research/补充素材/04-整页文档/竖屏滚动/` 下的同名文件 | 复制 [03-官方整页](03-官方整页/整页目录.md)，在副本根运行 `node 制作整页滚动.mjs`，用随包的四张整页 PNG 离线生成视频，输出在 `竖屏滚动/`。需要 Node.js、FFmpeg 和 ffprobe。 |

需要原始交付字节时，先核对本机原导出的大小和 SHA-256，再按清单相对路径复制。重新导出后也要对照清单；编码器、浏览器或字体版本变化可能产生不同字节，应把哈希不同的重建版本另存。
