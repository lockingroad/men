## 手机 Type-C 线可以复用吗？

**可以。推荐用现有 USB 充电头＋手机 Type-C 线，给 ESP32-S3 开发板供电。**

| 现有物品 | 怎么用 | 是否另买 |
| --- | --- | --- |
| 普通 USB 充电头 | 使用其 5V 输出；建议额定输出至少 1A，已有 5V/2A 充电头也可以 | 已有就不买 |
| 手机 Type-C 线 | 插开发板的 Type-C 口；烧录程序时换接电脑，线必须支持数据传输 | 已有可传数据的线就不买 |

USB-A 转 Type-C 线通常更省事。双头 Type-C 线是否能给第三方开发板供电，还取决于开发板的 USB-C 实现；若 C-C 线接充电头后不亮，先用已有 A-C 线测试。

如果你指的是“直接插安卓手机或 iPhone，让手机给开发板供电”，还需要具体手机支持 USB 对外供电，并满足整机电流要求；本清单不依赖这一功能。手机通过 BLE 操作即可，不必一直插线。

## 简单接法

```text
Android / iPhone ── BLE蓝牙 ──> ESP32-S3 ── SPI/控制线 ──> CC1101 ── 配套天线
                                  ↑                         ↑
现有5V充电头 ── Type-C线 ──> 开发板USB口             开发板3V3与GND
```

1. 拧好 CC1101 配套天线，断电状态下连接杜邦线。
2. **ESP32-S3 的 3V3 接 CC1101 的 VCC，GND 接 GND。不要把 5V 接到 CC1101。**
3. 接 SPI 的 SCK、MOSI、MISO、CSN，以及固件需要的 GDO0 / GDO2。按模块引脚图和固件 GPIO 配置接，不按排针位置猜。
4. 通过电脑 USB 烧录固件；日常使用时再换接充电头。

直插版 E07-M1101D-SMA 的厂家资料给出典型 3.3V 供电、最大发射功率下典型约 29mA 电流，所以优先使用开发板板载 3.3V 电源，省掉独立稳压板。具体第三方开发板的 3.3V 剩余供电能力尚未实测；确认能给外设留出至少约 50mA 余量后使用此接法。[厂家参数](https://www.ebyte.com/product/57.html)

本方案不需要额外蓝牙模块、电平转换板或 USB 转串口下载器。ESP32-S3 自带 BLE；购买链接中的开发板已有 USB 接口。硬件接好后仍需烧录 BLE＋CC1101 控制固件，不是上电后手机就能直接控制卷帘门。

可以复制给模块卖家询问（尚未代你发送）：

## 下单前只需确认两件事

- **实物可直接连线：**两块板已装好排针，CC1101天线配套；ESP32-S3板载3.3V可提供所需外设电流。现有Type-C线支持电脑数据传输。
- **卷帘门协议能配合：**433MHz只是频段，仍需确认实际频点、调制和编码方式。滚动码控制器不能假设通过普通录制重放就能使用；硬件采购不等于协议适配已经完成。
