# 抖音纯口稿

门壹修的口稿给枣强周边遇到门体故障的店主、住户和使用者听。选一个他们会直接问的问题，从本次现场或实物中选一个能说明问题的细节，用适合知性女声配音的短句讲清楚。先看[已有作品](../content/INDEX.md)，避免和上一期重复。

用户要“纯口稿”时，把下面两段写进对应作品目录，换成实际内容。时长、开头和收尾按本期需求调整。

```markdown
## 背景

这期回应谁遇到的什么问题？用一两句交代手头的实物、现场现象或已核实的依据。

## 口稿

用观众会问的一句话开头。接下来按实际发生的顺序讲清楚能观察到什么、该如何判断、下一步怎么办。正文里的每一句都应能直接送去配音。
```

“误插后灯不亮，改正接法再通电时跳闸”是一次现场经历。要把原因归到具体元件，还需检测结果。写脚本时保留这个区别。要做分镜或字幕时另列制作说明，保留一份可直接配音的正文。收到用户已定稿的文字时，按[归档技能](../.agents/skills/men-skill-douyin-archive/SKILL.md)保存原文。[控制器插头口稿示例](../content/控制器插头避坑version1/控制器插头避坑v1.md)
